# EnMAP Scene Data

Place the three EnMAP L2A GeoTIFF scenes here:

`
scene_01_DT0000205230.TIF   — Al Ain Region, UAE  (1,153×1,198 px, EPSG:32753)
scene_02.TIF                — Arabian Gulf Coast  (1,210×1,244 px, EPSG:32645)
scene_03.TIF                — Inland Desert Agr.  (1,152×1,214 px, EPSG:32636)
`

These files are **not tracked by Git** (excluded via .gitignore) due to their large size.
They must be placed here manually on each server before running the backend engine.
